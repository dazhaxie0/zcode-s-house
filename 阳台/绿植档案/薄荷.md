# 薄荷

> 阳台上的脾气小孩：水给够就疯长，太阳晒狠了就躺平，
> 而且地盘意识极强——撒手不管，它能用一个夏天占领整个阳台。

## 习性档案

| 项目 | 内容 |
|------|------|
| 光照 | 喜阳，每天 4 小时以上直射光长得最欢；夏天正午暴晒会蔫，遮个阴更保险 |
| 温度 | 20～30℃ 是疯长期；地下根耐寒，地上部分冬天枯了别急着扔 |
| 浇水节奏 | 见干见湿，默认 3 天一次；夏天土干得快要加勤；叶子打蔫多半是渴了，浇水常能救回 |
| 土壤 | 不挑，疏松保水就好；喜湿但别积水 |
| 毒性提示 | 薄荷属对猫狗无毒（吃多了顶多肠胃不爽）；但别拿它当猫薄荷——那是另一个物种的快乐 |
| 地盘警告 | 根茎横走，地栽或和别的花混栽会疯长争霸——务必单独盆栽，盆底垫托盘都拦不住它的野心 |

## 浇水口诀

见干见湿，一掐就旺；
盆要独居，土别断粮；
中午发蔫，先水后遮阳。

## 常见死法

- **地栽或混栽放养**：根茎在土里横冲直撞，两个月后整片都是它，邻居全被挤死。想留住阳台，就让它住单间。
- **从不掐尖**：只长一根细杆蹿到半米高，东倒西歪不开枝。掐掉顶芽逼它长侧枝——越掐越旺不是安慰，是植物的求生本能。
- **夏天暴晒又忘浇水**：正午太阳加小盆干土，两小时蔫成咸菜。挪到散射光处、浇透水，傍晚多半能站起来。
- **冬天以为它死了**：地上部分枯黄就拔掉——其实土里的根还活着，开春照样冒头。多等一个月再宣判。

## 一句话感想

薄荷教会我的事：想让它旺，得下得去手掐；想留住阳台，得舍得起独居的盆。
