# 多肉

> 全家最省心的住户，也可能是最容易被"爱死"的那一个——
> 在它的世界里，勤快是原罪，懒惰是美德。

## 习性档案

| 项目 | 内容 |
|------|------|
| 光照 | 喜光，秋冬全日照最容易出状态；缺光会徒长成豆芽，株型散了就回不去 |
| 温度 | 15～28℃ 舒适区；盛夏超过 35℃ 多数品种休眠，生长放缓属正常 |
| 浇水节奏 | 默认 12 天一次，再懒点也行；口诀"宁干勿湿"，浇就沿盆边浇透 |
| 土壤 | 颗粒土为主（泥炭掺珍珠岩、火山石），排水必须快，闷根是大事 |
| 通风 | 比浇水还重要；闷热潮湿又不通风，黑腐说来就来 |
| 毒性提示 | 常见景天类（胧月、白牡丹这类）无毒；但长寿花、虎刺梅对猫狗有毒，混养前先查清楚品种 |

## 浇水口诀

宁干勿湿，十二天一遭；
浇就浇透，盆底见水才算数；
管住手，是对它最大的好。

## 常见死法

- **太勤快，三天两头浇**：化水黑腐二连——叶片变透明、一碰就掉，茎干发黑。多肉旱不死，真能涝死。
- **闷养加积水**：不通风的角落配一盆湿土，等于给它蒸桑拿，黑腐一夜爆发。通风！通风！
- **长期缺光**：摊大饼、穿裙子、徒成豆芽，细高个再也憋不回胖墩。太阳是最好的整形医生。
- **夏天正午浇水**：高温加湿土，根系直接焖熟。要浇也等傍晚凉快了，沿盆边少量。

## 一句话感想

养多肉练的不是手艺，是忍住不动手的定力——对植物如此，对生活也差不多。
