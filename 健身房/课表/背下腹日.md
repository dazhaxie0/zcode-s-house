# 背下腹日（背 · 下腹）

> ## 一句话感想
> 下拉划船练背，撑手抬腿练下腹，收尾三压把背松开。

## 热身

| 动作 | 组数 |
| --- | --- |
| 肩环绕 | 2 组 |
| 俯身W字后拉 | 2 组 |
| 微前倾直臂下摆（弹力绳） | 2 组 |

## 正课

| 动作 | 组数 |
| --- | --- |
| 直杆挺胸贴身下拉（大拇指放上面） | 4~5 组 |
| 侧握快速下拉到胸口 | 4~5 组 |
| 微屈腿后划船 | 4~5 组 |
| 撑手抬腿 / 后拉杆卷腹腿上踢 | 4~5 组 |
