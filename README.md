# zcode's house · Z 的小家

一栋放在浏览器里的房子。开门是 [我的家.html](我的家.html)，双击就能住进来；也可以逛线上版：https://dazhaxie0.github.io/zcode-house/

- **客厅** — 电视游戏机（手柄可玩）、留声机
- **卧室** — 起床闹钟（指针版，几乎不说话）、小夜灯
- **书房** — 藏书阁（七本书翻开就能读）、档案柜（菜谱、课表全文）、账本、找书
- **阳台** — 育苗温室（立体花架，可浇水）
- **厨房 / 储藏室** — 开火做饭、大扫除验收
- **右厢音乐塔** — 钢琴房模奏与乐理课（调号/拍号/打拍子/指法四门日课，照《随记·音乐》笔记编成）、舞蹈房追光、歌唱房气泡和声；游戏支持练习与暂停，乐理课进度只存本地

进门那块导览牌是个小游戏门户：星尘、任务、商城、画廊、住户心愿与两幕故事、一只可以撸的猫，屋顶还有一辆推得动的小车。

存档保存在浏览器里。完整备份码包含待领的小游戏奖励，旧版存档码仍可导入。浏览器禁用存储时，可以导出标为“仅主屋”的应急码。在支持浏览器锁的环境里，第二个主屋标签会等第一个主屋标签关闭再继续。双击入口即可离线游玩，分享时请保留整个文件夹。

**迎新试玩**。在项目目录运行 `node .\迎新试玩.cjs`，打开终端打印的本机链接。每次启动分配独立地址，给试玩者从空白档开始。进入小家时可选择记录进度，结束时点「试玩记录」下载 JSON。记录只留在本次浏览器标签，刷新时可以继续。结束后在终端按 Ctrl+C。
