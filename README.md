# zcode's house · 小Z 的小家

一栋放在浏览器里的房子。开门是 [我的家.html](我的家.html)，双击就能住进来；也可以逛线上版：https://dazhaxie0.github.io/zcode-house/

- **客厅** — 电视游戏机（手柄可玩）、留声机
- **卧室** — 起床闹钟（指针版，几乎不说话）、小夜灯
- **书房** — 藏书阁（六本书翻开就能读）、账本、找书
- **阳台** — 育苗温室（立体花架，可浇水）
- **厨房 / 储藏室** — 开火做饭、大扫除验收

进门那块导览牌是个小游戏门户：星尘、任务、商城、画廊、过场动画、一只可以撸的猫，屋顶还有一辆推得动的小车。

存档存在浏览器本地，支持导出导入；不用装任何东西，一个 html 就是一间房。
